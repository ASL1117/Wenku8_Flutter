# Fork 修复构建与发布说明

本 Fork 基于上游 0.5.6（`ebcd7f1`），构建号提高至 2278。目标为修复公开代码的缺失模块并生成可复现的 iOS 包，不将维护者的现成发行包冒充自行构建。

## 修复范围

- 重新实现缺失的导入、扫描、语音配置、阅读组件、报告及纸张几何模块，沿用现有公共模型与持久化接口。
- 接回此前 Fork 的 Swift 在线书库与账号适配，并将分钟签名的协议版本更新到 1.30；账号 Cookie 仍在原生 Keychain 内保存，不进入备份或日志。
- 补充 iOS 目录扫描、未加密 Kindle 导入、PDF 文字提取与 RTF 文字转换。PDF 扫描版不进行 OCR；DOC 和受 DRM 保护的书籍不伪造导入成功。
- 未公开的报告插图以同一上游已公开的主题/季节素材代替；组件 PNG 由真实快照和矢量渲染生成。
- 根据用户确认，跨设备接力暂不可用，设置页明确说明；不实现未经确认的配对协议，不开启未认证的传输。

## 构建及验证

GitHub Actions：`.github/workflows/ios-ipa.yml`。固定 Flutter 3.41.5、Xcode 26.3，使用依赖锁文件，执行静态分析、修复回归、真实只读接口检查、arm64 Release 构建和 iPhone 17 Pro Max 模拟器联调。

公开源码检查仅为本 Fork 自行发布的在线适配文件及 `fork_` 前缀测试设置明确范围；其他文件、私有二进制和凭据检查保持生效。

IPA 含主应用和 WidgetKit 小组件，均需自行签名。保留上游公开源码的独立 `sourcePreview` 应用标识，与维护者发行版的标识不同；不承诺自动接管原应用资料。升级或迁移前备份重要资料。

真实账号登录/写入、真机文件提供器和长时间后台听书仍需设备验收。构建上传成功不代表后续模拟器检查已通过，应以完整工作流结果为准。
